# Creator interface font

Open Sans variable font, downloaded unchanged from the Google Fonts repository:
https://github.com/google/fonts/blob/main/ofl/opensans/OpenSans%5Bwdth%2Cwght%5D.ttf

Copyright 2020 The Open Sans Project Authors. Distributed under SIL Open Font License 1.1;
see OFL-OpenSans.txt alongside the font. The original font name and file are unmodified.
The CSS family alias is used only to scope dashboard, builder and results typography. No external font request
is required at runtime. Unsupported glyphs fall back to Arial, Helvetica, then sans-serif.

This is an approximate alternative, not a verified identification of Typeform's builder font.
